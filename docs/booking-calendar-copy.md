# The booking calendar — what to put in GoHighLevel

The calendar behind the "Book a diagnostic session" buttons is currently set up as
**"Discovery Call · 20 min"** with a description that promises a free consultation.
A buyer paying £1,200 + VAT for a 90-minute session meets a free-consult pitch before
they ever see a date. These are the two fields, ready to paste.

Everything below matches the wording already on the site, so nothing contradicts.

---

## Calendar name

```
TEAM IQ Diagnostic Session — 90 minutes
```

This is what the visitor sees as the heading above the calendar. It sets the price
expectation with the £1,200 offer page they just came from, so keep the duration in it.

## Description

```
Ninety minutes on the one area of concern — the late releases, the decisions that
never land, the team that will not raise a problem until it is a crisis.

We work the live problem with the people who own it. You leave with a written Team IQ
Score, a prioritised action plan, and two exercises from the relevant pillar to start
that week.

£1,200 + VAT, invoiced after the session, credited in full against a corporate
programme if you continue within six months.

Bring one paragraph describing the area of concern. We will send a short pre-read
beforehand and agree who needs to be in the room.
```

---

## While you are in there: the other fields that still say the wrong thing

| Field | Set it to |
| --- | --- |
| **Duration** | 90 minutes (currently 20) |
| **Location / meeting type** | Online — a joining link is sent with the confirmation. In person by arrangement. |
| **Availability** | Wide enough that a visitor can find a slot this week; a calendar with nothing free reads as a closed business. |
| **Confirmation message** | Keep it short: the time, the joining link, one line asking for the area of concern in a paragraph, and a note that we send a pre-read. |
| **Reminders** | One at 24 hours. The site promises "we reply within one working day" on the enquiry route, so make the reminder consistent with that tone: no exclamation marks. |

## Tone rules for anything you write in there

- Say what happens, not how excited we are. No "Amazing news!", no emoji.
- Money is stated plainly, in pounds, with VAT named: **£1,200 + VAT**.
- Never promise an outcome; promise the written output — the score, the plan, the two
  exercises. That is the claim the whole site is built on.
- If a field asks for a name, use the offer's name, not a generic one: *Diagnostic
  session*, not *Discovery call*.
